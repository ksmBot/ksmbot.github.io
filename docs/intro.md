# 🌟欢迎来到ksm的文档站
![ksm多可爱呀](./img/cafe.jpg)
你好！我是Daniel_Lin，你也可以叫我户山兔兔。欢迎你来到这里。下面让我们花一点时间介绍一下属于我的**KasumiBot**.

## 简述

ksm是由我（[Daniel_Lin(可跳转博客)](https://danieluu.top)）基于对Bot的爱好和兴趣独立开发的BangDream机器人。

本项目为完全免费，从未公开募集资金的纯公益项目，同时因为服务器/QQ风控等意外情况，因此也对可用性不做保证，同时我也会努力保证尽可能高的可用性。

ksm的词库和功能由我的朋友和我维护。主要基于调动群聊氛围考量，其中夹杂许多玩梗，致敬其他游戏/meme内容。所以可能存在许多的所谓“OOC”的情况。如果对此存在异议，可以友好协商，或者建议不要拉这个Bot。

对bot的建议和反馈欢迎寻找笔者协商和交流。

## 加群

ksm的系统已全面升级，新用户请认真阅读以下规则，然后点击网页中的开始认证的链接（我相信你认真读完能看见的），ksm将开始自动化流程添加的你的好友

如果这个流程出现问题，请联系我。（可能你的号加群被腾讯提示风险/我的服务刚刚好维护导致没收到等等）

系统只允许一个QQ号加一个群，如果要加多个，请联系开发者我。请理解，ksm的服务能力是有限的，如果可以的话，我希望让尽可能多的人也能用上我的服务。

在添加ksm前你应该知道的事；

1.一切加群相关行为已经得到了ksm开发者（也就是我，[QQ2370408621](https://qm.qq.com/cgi-bin/qm/qr?k=cUojLoZsBE0HvCHgOjuZOGNiJkZ06-z0&noverify=0&personal_qrcode_source=3)）的允许/或者自助申请被ksm自动审批通过。一般情况下，拉群是在会在我的QQ得到通知的，但是不排除少量小群可以直接添加ksm，如果不事先通知将会给我带来较大困扰。

**(一般来说你第一次添加ksm就会要求提供群号。但是，当你第二次添加ksm时，我希望你依然能够通知我一声，未被许可的加群将不会被自动加入ksm白名单被启用功能)**

2.请不要禁言ksm，这会对ksm的安全性造成较大问题，如果需要停用请使用/ksm off

3.你的群应该是邦邦群，你的群友最好也是邦邦人；

4.你已经受到了你的群管理员/群主的许可，同时你也应该是管理层级人员。非管理员拉群bot不会自动启动白名单；
